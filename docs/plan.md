# Plan of learning K8s

## Context

I'm figuring out how to learn k8s effectively for my MLOps role. I don't really have time to do it one step at a time so I have be critical about what to learn

## Goals

1. make sense of kube config & k3d operations.
    - know how to create a new cluster,
    - locate the configs and structuring them

2. learn container file systems and networkings as well as the linux APIs that supports those systems. (These are non-negotiable)
    - read iximiuz blogs and play around
    - structure the concepts of the container ecosystem internals

3. learn kubectl basics through the kubectl book, break things on purpose and document
    - internalize the commands
    - learn Kubernetes concepts and structure
